# Әдеби топонимдердің сандық карталары

М. Жұмабаев «Батыр Баян», М. Шаханов «Нарынқұм зауалы», М. Әуезов «Көксерек» шығармаларындағы жер-су атауларының ГАЖ негізіндегі интерактивті картасы.

## Құрамы
- `index.html` — сайттың өзі (карта, деректер, ойын — бәрі осы файлда)
- `img/` — авторлық инфографикалар (m1–m16)

## Жариялау
**Vercel:** репозиторийді GitHub-қа жүктеңіз → vercel.com → Add New → Project → репозиторийді таңдаңыз → Deploy (баптау қажет емес).

**GitHub Pages:** Settings → Pages → Branch: `main`, папка: `/ (root)` → Save.
